# Asset sources

- City Bloxx: https://citybloxx.antfootage.net/embed. The City Bloxx cover SVG uses original building sprites from the user's local City Bloxx project. The game runs remotely through its dedicated embed route.

- Website layout reference: https://poki.com/ (retrieved October 22, 2026).
- Game names and thumbnail artwork: Poki public game catalog, hosted at `img.poki-cdn.com`. Original game page URLs are preserved in `constants/games.json` as `sourcePage`. These assets are included to reproduce the requested reference interface; game code is not included. Replace the catalog with your licensed game assets for your own service.
- Brand logo and favicon PNGs: supplied by the user in `assets/`.
- Nunito typeface: Google Fonts, https://fonts.google.com/specimen/Nunito, SIL Open Font License. License included under `public/fonts/OFL.txt`.
- UI icons: Lucide, https://lucide.dev/, ISC license via `lucide-react`.
